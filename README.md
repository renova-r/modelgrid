# modelgrid

Provides a framework for creating, managing and training multiple caret models from shared and model-specific settings.

Compatibility updates by Renova.

Version 1.2.0.9001: Qualified the train documentation link to caret in R/model_grid.R and man/model_grid.Rd.

## Install

```r
install.packages("remotes")
remotes::install_github("renova-r/modelgrid@renova-1.2.0.9001")
```
